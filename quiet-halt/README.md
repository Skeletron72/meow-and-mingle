# Тихая Заводь

Уютный life-sim на **Godot 4.4** в духе *Animal Crossing: New Leaf*. Вы — новый смотритель
заброшенной станции в курортном городке: чините часы, зажигаете фонари, строите мост,
селите жителей-Ворсинок и разгадываете тайну пропавшей смотрительницы Лидии Верст.

Игра полностью **самобытная**: оригинальный сеттинг, персонажи, интерфейс и термины;
все модели, звуки и музыка генерируются кодом — внешних ассетов нет.

## Запуск

1. Установите [Godot 4.4+](https://godotengine.org/download) (стандартная версия, не .NET).
2. Откройте папку проекта (`project.godot`) и нажмите **F5**.
3. Платформы: ПК (Windows/Linux/macOS), мобильные (ландшафт), Web. Рендер — *Compatibility* (GL).

### Управление
| Действие | Клавиатура | Касание / мышь |
|---|---|---|
| Движение | WASD / стрелки (Shift — бег) | экранный стик (включается на тач-устройствах или в паузе) |
| Действие (говорить, трясти дерево, инструмент) | Пробел / F / Enter | большая кнопка «Действие» |
| Инструмент | 1/2/3 или Tab | значки инструментов |
| Рюкзак / Пауза | B / Esc | значки справа |
| Камера | Q / E, колесо (зум), ПКМ-перетаскивание | перетаскивание по экрану |

## Что уже есть (играбельный срез)
- **Вступление в вагоне**: диалог с проводницей Фетрой, имя, редактор внешности, название станции,
  **выбор полушария** (влияет на сезоны); приезд на перрон, где ждут три Ворсинки.
- **Время = системные часы**: сутки, дата, сезоны (с учётом полушария), детерминированная погода
  (ясно/облачно/дождь/туман/снег), смена листвы, снежный покров, звёзды, луна, ночные огни.
- **Город** с изогнутым горизонтом, пастельным светом и мягкими тенями.
- **Жители** гуляют по расписанию и спят ночью; разговор, расспросы, подарки, просьбы, дружба.
- **Действия**: тряска деревьев, сбор цветов, посадка семян и саженцев (растут по дням), рыбалка
  с поклёвкой, ловля бабочек и светлячков сачком, копание лопатой.
- **Экономика**: пуговицы, продажа и покупка в лавках, рюкзак (30 ячеек), коллекция рыб и насекомых.
- **Путевые листы** (аналог общественных проектов): 7 проектов, оплата, строительство к утру;
  мост открывает южный берег, проекты приводят новых жителей и открывают лавки.
- **Тайна**: 6 страниц журнала Лидии (блеск в земле), финальная сцена в полночь на перроне.
- Автосохранение, пауза, настройки, процедурный звук и «музыкальная шкатулка».

## Структура
```
scripts/autoload   Clock, Data, World, Game, Sfx — глобальные сервисы
scripts/core       WorldState (чистые данные), WorldGen, Weather, MeshKit, Mats
scripts/town       сцена города: terrain/objects view, окружение, игрок, жители, модели
scripts/ui         HUD, диалоги, окна, тач-управление
scripts/intro      вступление и создание персонажа
shaders            toon (изгиб мира, сезоны, снег), water, sky
data               items / objects / projects / villagers / notes (JSON)
tests              автотесты и скриншотеры
docs               DESIGN.md, ROADMAP.md
```
Подробности архитектуры (данные мира, команды, задел под мультиплеер) — в `docs/DESIGN.md`.

## Тесты
```
tests/run_all.sh        # нужны godot, xvfb, mesa (llvmpipe)
```
Скриншоты для проверки вида: `godot --path . res://tests/shot.tscn -- --date=2026-01-20 --hour=12 --out=/tmp/a.png`.

## Сборка
Пресеты экспорта (Windows, Linux, Web) лежат в `export_presets.cfg`; нужны шаблоны экспорта Godot.
Для Android добавьте пресет в редакторе (ориентация — ландшафт уже задана в проекте).
