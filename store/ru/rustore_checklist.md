# Чек-лист публикации в RuStore

Отмечено ✅ — готово в репозитории; ⬜ — делает владелец (нужны ваши данные, аккаунты, подписи).

## 1. Аккаунт и документы
- ⬜ Кабинет RuStore Консоль: регистрация, проверка (самозанятый / ИП / ООО).
- ⬜ Реквизиты для выплат, налоговый статус.
- ⬜ Страница политики конфиденциальности (URL): текст готов в `docs/legal/PRIVACY_POLICY.md`, заполнить поля `[…]`, выложить на сайт / GitHub Pages.
- ⬜ Пользовательское соглашение (`docs/legal/TERMS.md`) на тот же сайт.
- ⬜ E-mail поддержки (support@…), указать в карточке и в игре.
- ⬜ Возрастная маркировка (6+), заполнить анкету в консоли.

## 2. Сборка
- ✅ Пакет `ru.warmpaw.cafe`, версия 0.1.0 (code 1), пресеты Android (APK, AAB, тестовый).
- ✅ Иконка приложения + адаптивные слои (`assets/icons`), совпадает с иконкой карточки.
- ⬜ Свой keystore (release): создать, хранить в секрете, **не коммитить**; прописать в `export_presets.cfg` локально.
- ⬜ Экспорт: Godot 4.7 + Android SDK/JDK + шаблоны; команда в `docs/release/04-technical-export.md`. RuStore принимает APK (подпись своим ключом) и AAB.
- ⬜ Проверка на 2–3 реальных телефонах (слабый Android 8–9, обычный, с вырезом): выемка/safe area, звук, сворачивание, сейв.
- ⬜ Тест через закрытое тестирование в консоли (до публикации).

## 3. SDK RuStore (в коде есть заглушка `Platform` / `DummyBackend`)
- ⬜ RuStore Billing: покупки «Без рекламы», стартовый набор, сезонный пропуск (только если нужны на запуске; можно выпустить без покупок и добавить во 2-й версии).
- ⬜ Реклама за награду (Яндекс Реклама / VK Ads / MyTarget): подключить в `Shop.show_ad` (единственная точка). Без SDK кнопка «×2 (реклама)» работает как тестовая заглушка: **перед релизом либо подключить SDK, либо скрыть кнопки** (`Platform.feature("ads")`).
- ⬜ RuStore Review (оценка после 5-й смены), Update (мягкое обновление).
- ⬜ AppMetrica (аналитика): события из `docs/release/06-roadmap-and-metrics.md`.
- ⬜ Облачные сохранения: опционально (RuStore не даёт готового API, можно позже).

## 4. Карточка
- ✅ Название, краткое и полное описание, ключевые слова: `store/ru/listing.md`.
- ✅ Иконка 512×512: `store/ru/icon/icon_512_a.png` (PNG ≤ 3 МБ).
- ✅ 9 скриншотов 1080×1920 с подписями: `store/ru/screenshots` (минимум 2, берём 8).
- ✅ Трейлер mp4 H.264 1080×1920, 32 с, 6 МБ: `store/ru/video/trailer_1080x1920.mp4`.
- ⬜ Тексты: перечитать на опечатки и сверить с лимитами консоли.
- ⬜ Контакты, сайт, ссылка на политику.

## 5. После публикации
- ⬜ Заявка на фичеринг (подборка «Новинки» / «Казуальные»); в письме: трейлер, 3 скриншота, что в игре уникального.
- ⬜ Отвечать на отзывы в течение 48 часов.
- ⬜ Метрики 7 дней: установки / D1 / сбои (пороги в `docs/release/README.md`).
