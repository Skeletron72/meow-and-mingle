# Meow & Mingle — прототип (этапы 1–2)

Открыть папку в Godot и нажать F5. Портрет 360×640.

Игра открывается сразу **в кафе**, в городе (`scenes/city.tscn`). Отдельного главного меню нет: прогулка, готовка и меню
связаны в одну игру.

### Город и кафе (всё бесшовно)
- **Дверей нет.** Из проёма входа сразу тротуар; у кота один узел и один мир. Путь с улицы в зал и обратно строит общий поиск пути
  (`WorldNav`, сетка 32 px): достаточно тапнуть по залу или по тротуару — кот сам пройдёт через проём. Кнопок «Войти/Выйти» нет.
- **Рентген — пиксельная диафрагма.** Как только кот заходит в здание, вокруг него расходится круг (край ступенчатый, по сетке
  пикселей арта, с тёмным кольцом) и вырезает фасад, открывая интерьер; вышел — круг сжимается к коту. Мебель и гости внутри
  обрезаются тем же кругом (шейдеры `assets/shaders/xray_hole.gdshader` и `xray_clip.gdshader`). Тап по фасаду кафе ведёт
  кота внутрь, по соседним домам — «Здесь закрыто».
- **Коты-посетители** сами заходят в кафе и выходят: идут тем же путём через проём. Гость внутри не виден, пока фасад закрыт.
- **Улица широкая (около 2600 px) и уходит за дома:** между домами проходы (≥ 3 клетки) на задний двор с травой, деревьями,
  кустами и столиком. Камера едет за котом по обеим осям.
- **Машины** едут по двум полосам и не наезжают друг на друга: держат дистанцию и тормозят за медленной (`Traffic`, `Car.drive`).
- **Время суток** (`TimeOfDay`): сутки идут 6 реальных минут; утро/день/закат/ночь меняют свет улицы, небо, солнце и луну,
  ночью светятся окна, фонари и фары. Внутри кафе ночью теплее и светлее. Нажатие на часы перематывает на час. Час сохраняется.
- **Смена**: у стойки (чашка над ней) кнопка «Смена» (или тап по стойке) — готовка идёт поверх города, без смены сцены; кнопка
  выхода в углу заканчивает смену и показывает итог (подано / заработано).
- **Меню** внутри игры — шестерёнка справа вверху (пауза): продолжить, украшение, время +3 ч, выход (на ПК).

### Редактор улицы — `scenes/street.tscn`
Откройте сцену в Godot: здания, предметы и зоны — обычные узлы, которые двигаются мышью (в редакторе рисуется сетка 32 px).
- `Buildings` — узлы `StreetBuilding` (позиция = левый нижний угол фасада; галочка `is_cafe` — наше кафе, оно «рентгеновское»).
- `Props` — узлы `StreetProp` (позиция = точка на земле; `blocks` — кот не пройдёт, `emits_light` — фонарь светит ночью).
  Новый предмет: добавьте узел `StreetProp` и задайте текстуру из `assets/street/props`.
- `Ground` — земля: слой `TileMapLayer` с тайлсетом (см. ниже); рисуйте прямо в редакторе.
- `Zones` — узлы `StreetZone` (рамка с ручками размера, вид выбирается в инспекторе): `WALK` — где можно ходить, `BLOCK` — запрет,
  `LANE_EAST`/`LANE_WEST` — полосы машин (**низ рамки = линия колёс**), `CAFE_INTERIOR` — где стоит интерьер (320×320, угол: x кратен 32,
  (y + 96) кратен 32 — редактор предупредит). Проходы между домами и задний двор — тоже зоны `WALK`.
- В игре **F3** показывает зоны поверх города. Сцену `street.tscn` я сгенерировал один раз (`tools/generators/`): дальше её правите вы — повторный запуск генераторов сбросит уровень.
  Предметы с `blocks` не должны замыкать тротуар по диагонали — иначе кот не пройдёт (тест `modes_test` проверяет связность).

### Тайлсет земли
Тайлсет — `assets/street/tiles/street_tiles.png` (тайлы 16×16) + `street_tileset.tres`; таблица тайлов — `assets/street/tiles/README.md`.
Перерисовывайте тайлы в PNG (координаты не менять) или докрашивайте слой `Ground` в редакторе. Зебра — отдельный тайл: полосы идут
вдоль движения, под ней другой разметки нет. Здания и предметы — `assets/street/buildings`, `props`, машины — `vehicles`.

### Коты
У каждого кота три листа: `cat-<имя>-front/-side/-back.png` (`assets/cats`, взяты из пака neko-cafe). Вниз кот идёт лицом, вверх —
спиной, вбок — боковым листом (влево отражается); ходьба — 4 кадра нижнего ряда листа.

### Новая игра: игра раньше истории
Заставка (один кадр «Мама оставила кафе. Пора его открыть!», кнопка «Играть») → **обучающая смена из 3 заказов** (кофе, чай, кофе: первая чашка к 15-й секунде) →
**3 звезды** за обучение (провалить нельзя) → карточка «Ремонт кафе»: **ставни за 1★** (тап по рукe, 2 толчка «Ставни — пяткой!») →
**расчистка зала за 2★** (21 тап: паутина, пыль, шторка, три коробки, покрывало, кофемашина, стол, стул; в коробках 20 монет, рецепт «папин латте», фото родителей) →
свободная игра (смены-уровни у стойки). Герой — Мяу, кафе — «Тёплая Лапка». Остальные 5 панелей комикса лежат в **Меню → Дневник**
и открываются за 3-ю, 6-ю, 9-ю, 12-ю и 15-ю смены. Стадии вступления (`GameState.intro_stage`): 0 заставка, 1 обучение, 2 ставни, 3 расчистка, 5 готово.
Звёзды: `GameState.stars_total/stars_free`, ремонт — `data/repairs.json` + `GameState.do_repair`. Подробности и тексты — `docs/intro/DESIGN.md`
(исходный дизайн), порядок и цели скорости — `docs/release/01-ftue-and-core.md`. **Сбросить прогресс** (и пройти вступление заново): Меню → Настройки → Аккаунт.

### Слой платформы, язык, сохранение, настройки
- **`Platform`** (автозагрузка) — единая точка для аналитики, рекламы, покупок, облачного сейва, отзывов и push. Сейчас бэкенд `DummyBackend`
  (события пишутся в `user://analytics.log`, реклама «смотрится» сразу, покупки проходят только в отладочной сборке). Каналы подключаются подклассами
  `PlatformBackend` (RuStore, Яндекс Игры). Игра зовёт `Platform.track("level_end", {...})`, `Platform.show_rewarded(...)`, `Platform.purchase(...)`.
- **`Loc`** (автозагрузка) — язык. Строки в коде русские, английский — `data/loc/en.json` (русская строка → английская); подписи Control переводятся сами,
  для форматных строк пишем `tr("Подано: %d") % n`. `python3 tools/loc_check.py` показывает непереведённое. Язык: «Авто» (по системе: русскоязычные → ru, иначе en) / Русский / English.
- **Сохранение v5** (`user://save.json`): запись во временный файл, прошлое сохранение → `save.bak`, поле `crc`; повреждённое/изменённое вручную сохранение заменяется запасным.
  Настройки (`GameState.settings`: язык, громкость музыки и звуков, качество, аналитика) переживают сброс прогресса.
- **Аудит ассетов и лицензий:** `python3 tools/audit_assets.py [--strict]`, сводка — `docs/legal/ASSET_LICENSES.md`. Черновики политики и соглашения — `docs/legal/`.
- **Ремонт кафе** (S3): звёзды со смен тратятся на задачи ремонта (`data/repairs.json`, 30 задач по главам 1–3 на 55★): кнопка ★ в шапке или Меню → Ремонт
  (`RepairBoard`). Задача: `cost`, `requires` (дерево), `after` (сколько уровней пройти), `effects` — мебель в зал, цвет стен/пола/плинтуса на выбор
  (`data/styles.json`), улучшение, открытие напитка/выпечки/кота (`GameState.unlocks`: `drink:cocoa`, `source:syrup`, `pastry:eclair`, `cat:bulka`), монеты.
  Улучшение, купленное за монеты, закрывает связанную задачу без звёзд (`sync_repairs`). Проверка данных и экономики звёзд — `python3 tools/check_content.py`.
- **Контент S3:** 7 напитков (эспрессо, чай, латте, матча, какао, облепиховый чай, раф) и 5 видов выпечки; молоко и сироп стоят на прилавке по краям,
  какао — третья основа на столе; на столе до трёх видов выпечки («меню дня» уровня, `pastry_menu`). Условия открытия — поле `needs` в `drinks.json`/`pastries.json`.
  30 уровней по 10 в главе (`data/levels.json` собирает `python3 tools/levels_tool.py gen`, там же симулятор `sim` по трём моделям игрока: цель скорости подбирается так,
  чтобы звезду получала заданная доля «средних» игроков). Типы посетителей: спешащий (терпение ×0,65, чаевые ×2 за быструю подачу), гурман (напиток + выпечка, цена ×2);
  у котов есть роль (Сухарик спешит, Баюн и Усов — гурманы).
- **Коты и сюжет:** 9 котов (`data/cats.json`; 6 новых — раскраски трёх листов, свои листы позже). Меню → Коты (`CatBook`): симпатия растёт с заказами, записи на 5/15/30-м
  заказе дают монеты и реплики. 9 сюжетных сцен (`data/story.json`, `StoryScene`) показываются после задач ремонта и концов глав (10/20/30-й уровни) один раз.
- **Удержание и деньги** (S4), всё в `GameState.meta` (сохраняется): `Economy` — рыбки (премиум-валюта), 4 бустера (`data/boosters.json`: заморозка терпения, двойные чаевые,
  автосборка на 3 заказа, помощь кота — прощает ошибку; выбираются в окне перед сменой `ShiftPrep`, если они есть), события аналитики на каждое движение валют;
  `Daily` — подарок дня (лента на 7 дней со стриком, `data/daily.json`), 3 задания дня + «ящик дня» (с 3-й смены, `data/quests.json`), офлайн-доход (с 5-й смены, до 8 ч,
  ставка растёт с ремонтом), подарок за возвращение через 3 дня, одно напоминание в окне 12–21 (разрешение спрашивается после 2-го сеанса); `Shop` — каталог
  `data/shop.json` (рыбки 49–999 ₽ с бонусом «первая покупка ×2», стартовый набор на 72 ч, «Без рекламы», «Мурлык-пасс»), покупки через `Platform.purchase`
  (награда только при успехе), восстановление покупок, предложение дня (`data/deals.json`), реклама за награду с дневными лимитами, принудительная реклама между сменами
  (не раньше 10-й смены и 2-го дня, раз в 4 мин, не при «Без рекламы»), сезонный пропуск на 30 ступеней (`data/season_1.json`, очки — звёзды и задания). Экраны: Меню → Магазин,
  Задания, Ещё → Мурлык-пасс; красная точка на шестерёнке; подарок/офлайн-доход/предложение показываются при входе по очереди. Проверка данных — `tools/check_content.py`.
- **Звук** (`Audio`, автозагрузка): шины Music/SFX, `Audio.sfx("coin")`, `Audio.music("city"/"shift")`. Все звуки и музыка **синтезируются**
  (`python3 tools/generators/make_audio.py` → `assets/audio/*.ogg`), права у проекта.
- **Качество** (`Quality`): Авто / Низкое / Высокое; «Авто» мерит FPS и понижается ниже 40. Отладочная панель FPS — F2.
- **Безопасная зона** (`SafeArea`): отступ интерфейса под вырез камеры, если он заходит в игровую область.
- **Экспорт:** `export_presets.cfg` (Android APK/AAB, Web для Яндекс Игр, Linux), как собрать и подписать — `docs/release/07-status-s0-s2.md`; CI — `.github/workflows/ci.yml`.
- Тесты: `modes_test.tscn` (игра), `platform_test.tscn` (Platform, Loc, сохранение, настройки, ремонт, меню, звук, качество, пресеты).

### Смена (готовка)
Коту приходит заказ-чек. Собери его **на подносе** на прилавке: перетащи основу (кофе/чай), молоко, выпечку со стола на поднос,
затем перетащи поднос коту. Корзина справа от прилавка очищает поднос. Молоко и выпечка открываются улучшениями («Молочник»,
«Витрина»). Эффекты: пар, брызги, сердечки, звёзды, летящие монеты, конфетти за быструю подачу, серии подряд.

### Текст на плашках
`Ui.label` ставит подпись на чётные пиксели (строки не прыгают на полпикселя), сама берёт узкий шрифт, если текст шире рамки, а что не влезло и в нём,
обрезает многоточием. Нижняя «тень» рамок учитывается: `Ui.SHADOW_CREAM / WOOD / BUTTON` — текст и кнопки держим выше неё (на кнопках это
`content_margin_bottom`). Шрифты импортируются с `oversampling=1`, чтобы пиксели букв не плыли на дробных масштабах окна. Анимации `Fx.hop`/`Fx.shake`
запоминают исходную точку, поэтому повторные срабатывания (монеты) не уводят иконку.

Замеры: `tools/ui_shots.tscn` снимает все экраны в масштабе 2× и пишет JSON с прямоугольниками, `tools/measure_ui.py <папка> m_menu.png …` меряет поля
по пикселям. Замеренные размеры рамок (контур 2 px, бортик 8 px; деревянная — 8 сверху и по бокам, 14 снизу) лежат в `Ui`; тест `_test_ui_layout`
проверяет те же вещи по узлам. Магазин и выбор смены листаются по 4 карточки: две строки шрифта в карточку иначе не помещаются.
Вывеска кафе — название «ТЁПЛАЯ ЛАПКА» собственным пиксельным шрифтом 5×7 на серой доске фасада (`PixelArt.sign_texture`).

### Сетка и масштаб
Вся графика — на сетке 16×16 пикселей арта, **1 пиксель арта = 2 логических пикселя** (клетка зала = 32 px):
спрайты, рамки интерфейса (nine-patch в масштабе 2) и шрифт (Galmuri11 размером 24 = 12 px шрифта × 2) рисуются в одном
масштабе, поэтому пиксели везде одного размера. Мебель занимает целое число клеток (`tiles` в `data/furniture.json`)
и хранится как клетка `(c, r)`. Поля nine-patch подобраны по текстурам — см. `Ui.patch_margins`.

Шрифты: Galmuri11 и Galmuri11 Condensed (кириллица + латиница, SIL OFL, `assets/fonts/OFL-Galmuri.txt`);
импортируются без сглаживания. Тема проекта — `assets/ui/theme.tres`.

### Пиксельный свет и объём
Паутина, пыль, рольставни, шторы и все эффекты света генерируются кодом **в разрешении арта** (`scripts/pixel_art.gd`, `PixelArt`)
и показываются с масштабом 2 без сглаживания — никаких мягких градиентов: свечение, лучи, конусы фар и тени — постеризованные
(3–5 ступеней) с дизерингом Байера. Общего экранного шейдера нет (блум/виньетка убраны — рисунок выглядел грязно). Небо — ступенчатый градиент (`sky_gradient.gdshader`);
тени зданий и мебели — `dither_shadow.gdshader`; окна кафе светятся цветом неба по времени суток (день — голубые с бликом, закат — оранжевые,
ночь — тёмные со звёздами); в зале — окна с лучами света, лужи света под лампами, затенение углов (AO).

Мини-игра готовки — «крупный план»: спрайты там в масштабе 4, поэтому и всё нарисованное кодом (стол-плитка 16×16, тарелки,
поднос, лампы, корзина) лежит на сетке 4 px и имеет обводку в один такой пиксель. Движение — только шагами по сетке
(`Fx.hop`, `Fx.rise_in`, `Fx.shake(step)`): без дробного масштаба и поворота. Плашка заказа — часть интерфейса, иконки там ×2.

### Погода, двери и окна
- **Погода** (`autoload/weather.gd`): ясно, дождь, туман, жара, снег. В настройках — «Погода: Авто / Ясно / Дождь / Туман / Жара / Снег»
  (хранится в сохранении); в авто-режиме сама меняется раз в 70–150 с. Параметры (снежный покров, влажность, сила осадков) уходят
  шейдерам глобальными uniform-ами (`[shader_globals]` в `project.godot`).
- **Снег и лужи ложатся шейдером** (`weather_surface.gdshaderinc`) по клеткам арта с дизерингом: на землю, дорогу (слабее),
  крыши зданий, кроны деревьев и верхний край предметов; в дождь земля темнеет, появляются лужи с кольцами от капель. Снег копится,
  пока идёт снегопад, и тает (в жару быстрее). Шейдеры: `weather_ground`, `weather_prop`, `xray_hole` (фасад кафе).
- **Снегопад** — частицы в мире (`snow_field.gd`): спрайты на сетке 2 px с голубой подложкой, стоят на месте при движении камеры. Снежный
  покров с рельефом: светлые склоны, голубые тени сугробов и края пятен (`weather_surface.gdshaderinc`).
- **Экранные эффекты** (`weather_screen.gdshader`, слой `WeatherFx`): косые капли дождя, туман тремя ступенями,
  знойное марево (сдвиг строк на целую клетку) и блик солнца. Внутри раскрытого зала погоды нет.
  Пасмурная погода серит небо, прячет солнце и звёзды, зажигает окна и фары раньше.
- **Свет кафе на улицу:** ночью перед витриной тёплое пятно на тротуаре, из открытой двери — луч.
- **Дверь кафе** (`auto_door.gd`): две стеклянные створки из текстуры фасада разъезжаются шагами по 2 px, когда рядом кот
  (свой или гость), и закрываются; пока проём заперт ставнями (интро) — закрыты.
- **Прозрачные окна:** боковые окна витрины и стекло двери прозрачны — сквозь них виден зал и гости (`glass.gdshaderinc`).
  Остальные окна (`window_glass.gd`) показывают комнату за стеклом (шторы, цветок, кот на подоконнике), отражение неба с бликами,
  капли дождя, запотевание в тумане и иней в снегопад.

### Служебка и второй этаж
- **Служебка** — маленькая комната (3×3 клетки) в правом заднем углу зала за невысокими штукатурными перегородками (левая идёт от задней
  стены, передняя — с проёмом): коробки, мешок кофе и лестница. Это часть зала (`cafe_room.gd`: `STAFF_CELLS`, `STAFF_DOOR`), без переходов.
  Пока не куплено улучшение **«Коморка»** (150), это закрытый чулан с досчатой крышей и заколоченной дверью (тап — подсказка). Мебель в
  служебку не ставится; в старых сохранениях стоявшая там мебель убирается с возвратом денег.
- **Лестница** (`space_prop.gd`) — деревянная, вид сбоку, с поручнем; до улучшения **«Второй этаж»** (300) заколочена.
- **Второй этаж — верх самого дома.** В спрайте кафе (`building4.png`) уже есть второй этаж: плоская крыша (верх 69 px арта) и кремовая стена
  с двумя окнами и вывеской до карниза (до 116 px); ниже — навес и витрина первого этажа. Комната второго этажа занимает именно этот верх
  фасада (3 клетки стены + 4 клетки пола = 224 px, `city.gd`: `UPPER_SIZE`), ничего не пристраивается. Поднявшись по лестнице, кот оказывается
  в этой комнате: круг рентгена вырезает только верх фасада, витрина и навес остаются целыми, у кота своя сетка ходьбы (`floor_nav.gd`),
  гости ходят внизу. Наверху: кровать, шкаф, книжный шкаф, торшер, диван на ковре, окна, фото мамы. **Кровать:** ночью Мяу спит до 7:00.

### Смены: уровни, звёзды, очередь
- «Смена» у стойки открывает **выбор смены** (`data/levels.json`): 6 уровней, следующий открывается после первой звезды на предыдущем.
  До обучения смену начать нельзя. Смена конечная: все коты уровня пришли — смена окончена, показан итог.
- **Три звезды:** смена пройдена (подано хотя бы пол-коты), **точность** (подано / все коты; ошибки и ушедшие — потеря) и **скорость**
  (среднее время ожидания до подачи). Новые звёзды дают +10 монет; прогресс хранится в сохранении (`level_stars`).
- **Очередь:** до трёх котов у стойки, у каждого свой заказ (иконки в плашке) и полоска **терпения**. Ждущий кот нервничает (пот), потом
  злится (краснеет, трясётся, «жилка») и уходит. Поднос подают любому коту из очереди — тот, над кем отпустили поднос.

### Ходьба
Кот ходит по центрам клеток зала (путь — `AStarGrid2D`) и по тротуару: тап или удержание по полу либо стрелки/WASD.
По залу гуляют посетители; тап по коту — узнать любимый напиток.

### Украшение
Внизу каталог мебели (`data/furniture.json`) — тап по карточке покупает предмет за монеты и ставит его на свободное место.
Мебель перетаскивается пальцем/мышью по клеткам; красная подсветка — ставить нельзя (занято, за краем зала, перекрыт проход
к стойке/двери). Панель «Зеркало / Убрать / Готово»: «Убрать» возвращает полную цену. Настенное (окно, доска) вешается
только на стену. Расстановка сохраняется в `GameState.layout`.

- `data/*.json` — коты, напитки, выпечка, мебель, расстановка по умолчанию (баланс правится без кода)
- `autoload/game_state.gd` — монеты и сохранение `user://save.json` (SAVE_VERSION)
- `scenes/city.tscn` + `scripts/city.gd` — игра: город, рентген-кафе, смена, меню; `scenes/street.tscn` — уровень улицы (редактируется); `scenes/decorate.tscn` + `decorate.gd` — украшение
- `autoload/time_of_day.gd` — игровые часы и палитра суток; `scripts/sky.gd` — небо; `world_nav.gd` — единая сетка ходьбы; `traffic.gd`, `car.gd` — машины; `street_zone/prop/building/level.gd` — узлы редактора улицы
- `assets/street/`, `data/street.json` — отобранные ассеты города (делает `tools/curate_street_assets.py` из `assets/packs`)
- `scripts/cafe_room.gd` — комната кафе (отрисовка, проверка размещения, пути), `cat_walker.gd` — ходячий кот
- `scripts/ui.gd` (кнопки/панели/иконки), `scripts/nav.gd` (переходы между сценами)
- `scripts/main.gd` — сцена кофейни, `cup_state.gd` — логика чашки, `cat_customer.gd` — кот
- `tools/smoke_test.tscn` — автотест цикла: `godot --headless --path . res://tools/smoke_test.tscn`
- `tools/modes_test.tscn` — автотест меню, прогулки и украшения (перезаписывает `user://save.json`!)
- `tools/screenshot.tscn` — снимок сцены: `xvfb-run -a godot --path . res://tools/screenshot.tscn -- res://scenes/menu.tscn out.png`

Сохранение: SAVE_VERSION 3 (+ время суток `hour`) (мебель — в клетках; старые v2 сбрасываются на расстановку по умолчанию с возвратом монет за докупленное).

Не сделано в этапе 1: время варки, главы/открытки, окна визитов по часам, магазин, реклама.
