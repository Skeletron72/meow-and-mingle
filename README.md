# Meow & Mingle — прототип (этапы 1–2)

Открыть папку в Godot и нажать F5. Портрет 360×640.

Игра открывается **главным меню**: Играть (кофейня), Прогулка по кафе, Украшение.

### Кофейня («Играть»)
Коту приходит заказ в пузыре. Перетащи на чашку основу (кофе/чай), затем молоко, затем выпечку с витрины.
Готовую чашку перетащи на кота. Корзинка справа от чашки очищает её.

### Прогулка по кафе
Кот-официант ходит по залу: тап или удержание по полу, либо стрелки/WASD. Путь строится вокруг мебели
(`AStarGrid2D`). Тап по стойке — кот идёт к ней и открывает кофейню; рядом со стойкой есть кнопка «Готовить».
По залу гуляют посетители; тап по коту — узнать любимый напиток.

### Украшение
Внизу каталог мебели (`data/furniture.json`) — тап по карточке покупает предмет за монеты и ставит его на свободное место.
Мебель перетаскивается пальцем/мышью; красная подсветка — ставить нельзя (занято, за краем зала, перекрыт проход
к стойке/двери). Панель «Зеркало / Убрать / Готово»: «Убрать» возвращает полную цену. Настенное (окно, доска) вешается
только на стену. Расстановка сохраняется в `GameState.layout`.

- `data/*.json` — коты, напитки, выпечка, мебель, расстановка по умолчанию (баланс правится без кода)
- `autoload/game_state.gd` — монеты и сохранение `user://save.json` (SAVE_VERSION)
- `scenes/menu.tscn`, `cafe_walk.tscn`, `decorate.tscn` + `scripts/menu.gd`, `cafe_walk.gd`, `decorate.gd` — меню и режимы
- `scripts/cafe_room.gd` — комната кафе (отрисовка, проверка размещения, пути), `cat_walker.gd` — ходячий кот
- `scripts/ui.gd` (кнопки/панели/иконки), `scripts/nav.gd` (переходы между сценами)
- `scripts/main.gd` — сцена кофейни, `cup_state.gd` — логика чашки, `cat_customer.gd` — кот
- `tools/smoke_test.tscn` — автотест цикла: `godot --headless --path . res://tools/smoke_test.tscn`
- `tools/modes_test.tscn` — автотест меню, прогулки и украшения (перезаписывает `user://save.json`!)
- `tools/screenshot.tscn` — снимок сцены: `xvfb-run -a godot --path . res://tools/screenshot.tscn -- res://scenes/menu.tscn out.png`

Не сделано в этапе 1: время варки, главы/открытки, окна визитов по часам, магазин, реклама.
