# Тайлсет земли улицы

Атлас: `street_tiles.png` (тайлы 16×16, сетка 8×4). Ресурс `street_tileset.tres` — TileSet с этим атласом; его использует слой
**Ground** (TileMapLayer, масштаб 2) в `scenes/street.tscn`. Клетка карты = 16 px арта = 32 px мира = клетка сетки ходьбы.

Можно перерисовать любой тайл в PNG (координаты не менять) или докрашивать землю прямо в редакторе: откройте `street.tscn`,
выберите `Ground`, на нижней панели «TileMap» берите тайлы и рисуйте.

| Клетка атласа | Тайл |
|---|---|
| (0,0) (1,0) (7,0) | тротуар: обычный, с трещиной, вариант |
| (2,0) | тротуар с тенью под фасадом (ряд у стены дома) |
| (3,0) | бордюр (нижний край тротуара) |
| (4,0) (5,0) | бетон проходов и задней дорожки; с трещиной |
| (6,0) | утоптанная земля (запас) |
| (0,1) (1,1) | асфальт и вариант |
| (2,1) | асфальт под бордюром (с тенью) |
| (3,1) | штрих разделительной (чередуется с обычным асфальтом) |
| (4,1) | зебра: полосы идут вдоль движения, пешеходы — поперёк. **Под ней разметки нет** |
| (0,2) (1,2) (2,2) | трава: обычная, светлая, тёмная |
| (3,2) | трава с цветочками |

Схема улицы (клетки по y): 0–2 небо · 3–8 задний двор (трава) · 9 дорожка за домами · 10–21 проходы между домами ·
22 тротуар с тенью · 23 тротуар · 24 бордюр · 25–29 дорога (27 — разделительная).
Файлы создаёт `tools/generators/make_street_tiles.py`; повторный запуск перезапишет PNG.
