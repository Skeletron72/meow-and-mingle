## Репозиторий

- Каталог `assets/packs/` — локальный архив исходников (в игру и в сборку не входит: `.gdignore` и исключение в экспорте).
  Оставлены только паки, из которых игра берёт файлы; остальные удалены.
- В истории git по-прежнему лежат удалённые паки (включая LimeZu Free и 329 МБ анимаций машин). Репозиторий публичный — **до релиза его
  нужно сделать приватным и очистить историю**:
  ```
  pip install git-filter-repo
  git filter-repo --path assets/packs/modern-interiors-free --path assets/packs/cosy-cabin \
                  --path assets/packs/pixel-16-interiors --invert-paths
  ```
  (это переписывает историю и требует force-push; делается один раз владельцем, остальным — заново клонировать).
- Музыка и звуки: только собственный синтез (`tools/generators/make_audio.py`) или купленные паки с чеком в `docs/legal/receipts/`.

## Что я не могу проверить сам

Доступ к страницам авторов и чекам — у владельца проекта. Для UNVERIFIED-паков нужно открыть страницу, прочитать лицензию (коммерческое
использование, правки, мобильные приложения, перепродажа) и положить скриншот в `docs/legal/receipts/`, затем сменить статус в `tools/audit_assets.py`.
