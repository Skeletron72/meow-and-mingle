# 06. Дорожная карта, критерии и метрики

Расчёт на одного основного разработчика и ИИ-ассистента; параллельно идёт арт/звук. Недели — рабочие. Параллельные ветки помечены.

## Спринты

| Спринт | Недели | Цель | Результат (Definition of Done) |
|---|---|---|---|
| **S0. Основание** | 1 | Права, бренд, оформление | таблица лицензий; запрещённые паки удалены из репо; интерфейс — решение «купить/перерисовать»; название проверено; ИП/самозанятость; домены, сообщества; политика конфиденциальности v1 |
| **S1. Вход и платформа** | 2–3 | FTUE и `Platform` | новое интро (см. 01), первый заказ ≤ 20 с; `Platform` с Dummy; сейв v5; события аналитики; локализация ru/en на ключах |
| **S2. Звук, сборки, слабые телефоны** | 3–5 | Устойчивый билд | музыка + SFX; Android-пресеты; APK на 6 устройствах; режим «Качество»; адаптация экрана; CI |
| **S3. Ремонт и контент I** | 5–7 | Метаигра | «Задачи ремонта» (система + 30 задач); уровни 1–30; напитки до 7; выпечка до 5; коты до 9; сцены глав 1–3 |
| **S4. Удержание и деньги** | 7–9 | Экономика | валюты `Economy`; ежедневка, задания, офлайн-доход, уведомления; магазин, рыбки, «Без рекламы»; реклама с наградой; RuStore Billing; AppMetrica |
| **S5. Контент II** | 9–11 | 60 уровней | главы 4–6, остальные задачи (60), коты 16, декор 90; события 1 + пропуск сезона 1; баланс по симулятору |
| **S6. Закрытая бета** | 11–12 | Качество | 50–100 игроков; правки по когортам; QA-лист; профиль и крэши |
| **S7. Soft launch RuStore** | 12–17 | Данные | публикация; метрики D1/D7/ARPDAU; быстрые патчи; AppGallery/GetApps |
| **S8. Яндекс Игры + live-ops** | 17–21 | Масштаб | веб-билд и SDK; лидерборд; первое событие; глава 7 |

Критический путь: S0 → S1 → S2 → S4 → S6 → S7. S3 и S5 (контент) идут параллельно с техническими задачами; звуковая и арт-работа (заказ) стартуют в S0.

## Критерии готовности спринтов (go/no-go)

| Перед этапом | Условие |
|---|---|
| Закрытая бета | все права чисты; нет блокеров краша; FTUE ≥ 85% на внутренней группе; 40 уровней; платежи и реклама на тестовых ключах |
| Soft launch | crash-free ≥ 99%; бета-D1 ≥ 30%; 60 уровней и все 60 задач; политика и оферта опубликованы; RuStore одобрил страницу |
| Публичный запуск | D1 ≥ 35%, D7 ≥ 10%, crash-free ≥ 99,5%; средний ARPDAU положительный (с учётом рекламы); нет нарушающих рейтинг багов |
| Платный трафик | органические D1 ≥ 35% и D7 ≥ 10%; окупаемость когорты рассчитана |

## События аналитики (минимум)

| Группа | События и параметры |
|---|---|
| FTUE | `ftue_step(step, t)`, `ftue_skip(step)`, `first_order_time`, `ftue_finish(t)` |
| Игра | `level_start(id, attempt)`, `level_end(id, result, stars_mask, accuracy, avg_time, served, lost)`, `order_served(drink, time)`, `cat_left_angry(cat)` |
| Ремонт | `task_start(id)`, `task_done(id, variant)`, `stars_short(task, need)` |
| Экономика | `currency_earn(type, amount, source)`, `currency_spend(type, amount, sink)`, `booster_use(id)` |
| Удержание | `daily_open(day)`, `quest_done(id)`, `offline_claim(coins, hours)`, `push_permission(result)`, `session(n, len)` |
| Монетизация | `shop_open(source)`, `offer_show(id)`, `iap_start(sku)`, `iap_ok(sku, price)`, `iap_fail(sku, reason)`, `ad_request(placement)`, `ad_show(placement)`, `ad_reward(placement)`, `ad_fail(placement, err)` |
| Техника | `perf(fps_avg, mem_mb)`, `crash`, `save_error`, `version`, `quality_level` |

Дашборды недели: воронка FTUE (по шагам), D1/D3/D7/D30, прохождение уровней (первая попытка, среднее число попыток), экономика (источники/стоки, баланс монет), реклама (fill, eCPM, просмотры на DAU), конверсия в платящих.

## Риски и ответы

| Риск | Ответ |
|---|---|
| Права на интерфейс/улицу не подтверждаются | заменить за 1–2 недели; заложено в S0 |
| Плохое D1 из-за сложности | A/B-подсказки, гарантированные звёзды в первых 10 уровнях |
| Слабые телефоны не тянут шейдеры | режим «Качество», отключаемая погода |
| Реклама ухудшает удержание | только по желанию до 10-й смены, ограничитель |
| Недостаточно контента | события и повторяемые режимы («Ночная смена», недельный турнир) |
| Изменение условий площадок | `Platform`-слой, не завязываться на одну сеть/магазин |
| Потеря ключа подписи | резервные копии в двух местах до первого релиза |
| Низкий органический охват | ASO + фичеринг, платный трафик только при хороших когортах |
