## Главное в одном абзаце

Игра уже имеет рабочее ядро (смена за стойкой, очередь котов, звёзды), мир (город, погода, два этажа) и сюжетный задел. До релиза не хватает
пяти вещей: **(1)** чистых прав на графику, **(2)** звука, **(3)** сборок и платформенного слоя (RuStore, Яндекс Игры), **(4)** метаигры вокруг
звёзд (ремонт кафе задачами, как в Homescapes) и контента на первые 8–10 часов, **(5)** удержания и монетизации (ежедневные награды, задания,
офлайн-доход, пропуск сезона, косметика, реклама по желанию). Первое впечатление нужно перестроить: сейчас до первой настоящей смены проходит
несколько минут комикса и уборки, цель — **первый заказ на 15-й секунде**.

## Цели релиза (мягкий запуск, RuStore)

| Метрика | Цель | Порог «не запускать дальше» |
|---|---|---|
| Время до первого заказа | ≤ 20 с | > 40 с |
| Прошли обучение (3 смены) | ≥ 85% | < 70% |
| Удержание D1 / D7 / D30 | 38% / 12% / 4% | D1 < 28% или D7 < 7% |
| Сессия (среднее) | 7–10 мин, 3 сессии в день | < 4 мин |
| Crash-free сессий | ≥ 99,5% | < 98,5% |
| Холодный старт на слабом телефоне | ≤ 4 с | > 7 с |
| Размер установки | ≤ 80 МБ | > 150 МБ |
| Платящие (от всех, на 30-й день) | 1,5–3% | < 0,7% |

Это ориентиры для казуальных игр, а не гарантии: их надо перепроверять на реальной когорте мягкого запуска.
