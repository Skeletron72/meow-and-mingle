## 6. Сюжет: честная оценка

Что есть: сильная завязка (мама оставила кафе, письма), шесть глав по 10 уровней, 16 котов с характерами, шутливые реплики (Тучка: «Я не мешаю. Я — облачко.»), финал «Мама вернулась!».
Слабое место: на всю игру 18 сцен, около 54 реплик, то есть сцена каждые 3–4 уровня. Для 60 уровней и десятков часов метаигры этого мало; тайны, которые мы обещаем в описании («тайный гость»), держат интригу только на финале.
Что сделать после релиза (по убыванию отдачи):
1. Мини-сцены у каждого кота при росте дружбы (3 сердечка → личная история): 16 котов × 2 сцены.
2. Сквозная загадка: каждая глава заканчивается письмом мамы с одной деталью, из которых к главе 6 складывается ответ.
3. Событийные истории (сезоны, праздники) как короткие арки по 3–4 сцены.
Оценка: для первой версии **достаточно, чтобы не мешать**, но продающим аргументом сюжет не станет; продаёт скорее «коты + уют».

## 7. Геймплей: честная оценка

Сильное: двухслойная петля (смена ↔ ремонт/декор), хорошая «глубина» без перегруза (основа, молоко, сироп, добавки, остывание, загадки), понятный поднос.
Риски:
- **Повторяемость смен**: механика подносов не меняется после главы 3. Заложены гости-загадки, остывание, ураганные гости; стоит добавлять «событие смены» (кот-критик, час пик, VIP-заказ).
- **Экономика не проверена живыми игроками**: модель (`tools/economy_sim.py`) даёт порядок величин, но не поведение. Закладывайте первые 2 недели мягкого запуска на подгонку цен.
- **Сложность по главам**: кривая по расчёту плавная; реальный D1/D7 покажет, не слишком ли жёстки главы 3–4.
- **Нет соревновательного слоя** (рейтинг, друзья). Для казуалок RuStore это не обязательно.
