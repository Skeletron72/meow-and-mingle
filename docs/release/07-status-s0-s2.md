## Как собрать (на машине с редактором Godot 4.7 и шаблонами экспорта)

1. Android SDK + JDK 17 → в Godot: Editor Settings → Export → Android (пути SDK, debug.keystore).
2. Релизный ключ (один раз, **хранить в двух местах**, без него нельзя обновлять приложение):
   `keytool -genkeypair -v -keystore warm-paw.keystore -alias warmpaw -keyalg RSA -keysize 2048 -validity 10000`.
3. Переменные для подписи (не в репозитории): `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `…_USER`, `…_PASSWORD`.
4. `godot --headless --path . --import`, затем `--export-release "Android (RuStore, APK)" build/android/warm-paw.apk` (для AAB включить gradle-сборку и установить шаблон Android).
5. Идентификатор пакета `ru.warmpaw.cafe` — **заглушка**: заменить на свой домен до первой публикации (потом менять нельзя).
6. Веб для Яндекс Игр: пресет «Web (Yandex Games)» (без потоков, т. к. iframe без SharedArrayBuffer); затем SDK Яндекса через `JavaScriptBridge` в новом `YandexBackend` (S8).
