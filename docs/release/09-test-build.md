# 09. Тестовая сборка и живой тест пальцем

## Пресеты (export_presets.cfg)

| Пресет | Файл | Для чего |
|---|---|---|
| `Android (TEST — debug APK, arm64)` | `build/test/warm-paw-test.apk` | телефон; пакет `ru.warmpaw.cafe.test` ставится рядом с обычным |
| `Web (TEST)` | `build/test/web/index.html` | быстрый просмотр в браузере телефона/ПК (без потоков, как для Яндекс Игр) |
| `Windows (TEST)` / `Linux (TEST)` | `build/test/windows/…`, `build/test/linux/…` | ПК, проверка мышью |

У всех признак `playtest`: панель FPS включена сразу, события пишутся в `user://analytics.log`, покупки «проходят» (заглушка), в Настройках появляется страница **«Для тестов»** (скопировать лог, панель FPS, «Открыть главу 4+», +1000 монет).

## Сборка

```
tools/build_test.sh android      # или web | windows | linux | all
adb install -r build/test/warm-paw-test.apk
```

Нужны шаблоны экспорта Godot 4.7 (Editor → Manage Export Templates), для Android — JDK 17, Android SDK и debug-keystore в Editor Settings → Export → Android.
**В среде разработки этого репозитория шаблонов экспорта нет, поэтому сами APK/web/exe не собирались**; проверено, что все четыре пресета читаются и пакет ресурсов (`--export-pack`) собирается (то же делает CI).

## Живой тест пальцем (P7): 5–6 смен подряд, включая главу 4

Подготовка: Настройки → Для тестов → «Открыть главу 4+», затем играть уровни 31–36 (начинки, загадки, остывание).

1. **Средняя полка (5 банок).** Крайние баночки (молоко слева, сливки справа) — не перехватываются ли системным жестом «назад»? Легко ли попасть в нужную из пяти в спешке? Если нет — добавить поля слева/справа или менять ширину ячейки (`Main._slots`).
2. **Подъём 48 px (`FINGER_LIFT`).** С верхней полки спрайт не упирается в верх экрана или плашку загадки? Видно ли поднос и его подсветку под пальцем?
3. **Половины подноса.** При броске сиропа/сливок/корицы, когда выпечка уже на подносе: понятно ли по белой рамке, куда ляжет добавка (кружка слева, выпечка справа)? Не ловится ли лишнее?
4. Шпаргалка: открывается одним касанием, во время неё смена стоит, после — гости не «сгорели».
5. Остывание и загадка: читаемы ли подсказки на плашке без очков/на солнце.

Критерии «хорошо»: промахов по крайним ячейкам не больше, чем по средним (+5 п.п.); начинки в нужную половину ≥ 90%; ни одного случая «потерял поднос под пальцем».

## Разбор лога

```
python3 tools/analyze_log.py analytics.log
```
Покажет по каждой баночке число бросков и долю промахов (края экрана помечены), распределение половин подноса, смены, открытия шпаргалки. Лог берётся из страницы «Для тестов» («Скопировать лог») или `adb shell run-as ru.warmpaw.cafe.test cat files/analytics.log`.
